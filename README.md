## Artifact Three: Databases

The third artifact is the Inventory Management Android Mobile Application, enhanced from a database perspective. This enhancement focused on improving the database architecture by adding user-specific inventory ownership, modifying database queries to filter records by authenticated user, creating inventory history tracking, and supporting a more secure multi-user design. These changes improved data integrity, accountability, scalability, and security while preserving the original inventory management functionality.
